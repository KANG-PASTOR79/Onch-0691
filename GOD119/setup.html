실시간 강의실 연결 안내

기존 GitHub 사이트를 유지하면서 강사 PC와 참석자 PC의 화면을 연동하는 설정입니다.

참석자 화면 열기강사 화면 열기Firebase Console 열기

먼저 확인하세요

현재 사이트는 원본 PPT 이미지와 노트북의 개인 영상·문서를 업로드하지 않은 보안 미리보기입니다. Firebase 설정이 끝나야 실제 두 노트북 사이의 슬라이드 이동·필기가 실시간 전달됩니다.

Firebase는 저장소가 아니므로 GitHub Pages만으로는 실시간 공유 기능을 사용할 수 없습니다.

01 / Firebase 프로젝트

프로젝트 생성

  1. Firebase Console에서 Google 계정으로 로그인합니다.
  2. 새 프로젝트를 만든 뒤 웹 앱(</>)을 등록합니다.
  3. 웹 앱에 표시되는 firebaseConfig의 apiKey, authDomain, databaseURL, projectId, appId 항목을 확인합니다. 서비스 계정 비밀키를 내려받거나 웹사이트에 넣지 마세요.

02 / 실시간 데이터베이스

Realtime Database 만들기

  1. Firebase 왼쪽 메뉴에서 Build → Realtime Database를 열고 데이터베이스를 생성합니다.
  2. 시작 보안 모드는 잠금 모드(Locked mode)를 선택하세요. 테스트 모드에서는 불특정 사용자가 데이터를 기록할 수 있습니다.
  3. databaseURL을 웹 설정에 포함합니다.

03 / 강사 로그인

Google 인증 활성화

  1. Authentication → Sign-in method에서 Google 로그인 제공업체를 활성화합니다.
  2. Authentication → Settings → Authorized domains에 kang-pastor79.github.io를 추가합니다.
  3. 이제 강사 화면에서 Google 계정 로그인 버튼을 이용할 수 있습니다.

04 / 사이트 연결

공개용 웹 설정 입력

GitHub GOD119/config.js를 열어 Edit에서 Firebase 웹 앱 설정 값을 넣고 저장합니다. 형식을 바꾸지 말고 따옴표 안의 값만 입력하세요.

Firebase Web Config는 브라우저에 표시되는 식별 정보입니다. 접근 권한은 API 키를 숨기는 방법이 아니라 실시간 데이터베이스 보안 규칙으로 보호해야 합니다.

05 / 강사 권한

강사 UID 등록

  1. 강사 화면(GOD119 강사 제어실)에 접속하여 Google 로그인을 합니다.
  2. 화면에서 내 UID를 복사합니다. 이 문자열을 참석자에게 보낼 필요는 없습니다.
  3. GitHub에 저장된 보안 규칙 예시 파일을 확인합니다.
  4. Firebase Realtime Database → Rules에서 예시 규칙을 붙여넣고 REPLACE_WITH_PRESENTER_UID를 강사 UID로 바꿉니다.
  5. Publish를 누르고, 수정한 규칙을 공개 GitHub 저장소에 다시 올리지 않습니다.

이 설정에서는 참석자 인증 없이 실시간 슬라이드 번호·판서 데이터는 읽을 수 있지만, 변경할 수 있는 사람은 지정된 강사 UID뿐입니다. 공개 열람 데이터에는 개인정보를 기록하지 마세요.

06 / 두 대의 기기로 확인

실제 동기화 테스트

  1. 강사 노트북: 강사 링크를 열고 로그인합니다.
  2. 참석자 노트북: 참석자 링크를 엽니다(로그인 불필요).
  3. 강사 화면에서 슬라이드를 한 장 넘깁니다 → 참석자 화면 페이지 번호가 바뀌는지 확인합니다.
  4. 강사 화면에서 펜으로 동그라미를 그립니다 → 참석자 화면에도 그려지는지 확인합니다.
  5. 연동이 되지 않으면 먼저 Firebase 웹 설정·승인 도메인·Realtime Database Rules를 점검합니다.

개인정보 및 저작권 보호

원본 PPT의 교회 사진, 가족·성도 이름, 개인 이메일·전화번호, 개인 영상, 노트북 로컬 파일 경로는 내용 검토와 허락 전까지 공개 사이트에 게시하지 마세요. GitHub 공개 저장소에 업로드한 파일은 검색·복사·다운로드될 수 있습니다.
