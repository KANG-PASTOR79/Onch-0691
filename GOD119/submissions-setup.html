실습 제출 개인정보 보호 설정

이 페이지는 초기 설정 안내입니다. GitHub 사이트에 UID나 개인정보를 저장하지 않으며, 보안 규칙은 목사님이 Firebase 콘솔에서 직접 게시해야 적용됩니다.

현재 데이터베이스 규칙을 반드시 보존하세요.

아래 설정은 기존 슬라이드·판서 접근 권한을 유지하고 별도의 비공개 ‘실습 신고’ 경로를 추가한 전체 규칙 예시입니다. Firebase에서 기존 규칙을 먼저 복사해 보관한 뒤 적용하세요. 기존 규칙을 별도로 변경했다면 그대로 덮어쓰지 말고 두 설정을 병합해야 합니다.

1 · 참석자용 익명 인증 활성화

  1. Firebase 콘솔 → GOD119 프로젝트를 엽니다.
  2. Authentication → 로그인 방법(Sign-in method)으로 이동합니다.
  3. 익명(Anonymous) 제공업체를 사용 설정하고 저장합니다.

참석자는 Google 로그인을 요구받지 않습니다. Firebase가 임시 익명 UID로 자신의 신고만 저장·조회하게 됩니다. 동일 계정으로 신고한 내용만 다시 볼 수 있습니다.

2 · 강사 전용 UID 입력 및 규칙 만들기

기존 GOD119 강사 화면에 Google 로그인 후 표시되는 내 UID를 복사해 아래 칸에 붙여넣으세요.

이 UID는 이 페이지에서 규칙 코드를 만들 때만 사용합니다. GitHub로 전송하거나 웹사이트에 저장하지 않습니다.

UID를 입력하면 규칙을 생성할 수 있습니다.

이곳에 Firebase 보안 규칙이 표시됩니다.

3 · Firebase Realtime Database에 규칙 게시

  1. Firebase 프로젝트 → Realtime Database → 규칙을 엽니다.
  2. 현재 규칙을 백업한 뒤, 위에서 복사한 전체 규칙으로 바꿉니다.
  3. 게시(Publish)를 눌러 저장합니다.

이 단계를 끝내지 않으면 참석자 신고와 강사 현황판은 작동하지 않습니다. Google 로그인 제공업체는 그대로 유지하세요.

4 · 두 기기로 테스트

  1. 참석자 제출 페이지에서 MEGA 시험 업로드 후 완료 신고를 누릅니다.
  2. 강사 전용 현황판에 로그인한 뒤 신고가 나타나는지 확인합니다.
  3. MEGA에 파일이 실제 도착했으면 강사 화면에서 ‘MEGA 수신 확인’을 누릅니다.
  4. 참석자 화면에 ‘강사 확인 완료’가 표시되는지 확인합니다.

실제 수신 자동 확인은 지원하지 않습니다. 본인 신고이며, 다른 사람의 이름으로 허위 신고하거나 여러 기기로 중복 신고할 가능성은 남아 있습니다. 실습 명단과 MEGA 파일을 대조해야 합니다.
