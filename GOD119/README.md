# GOD119 · AI 목회자 세미나 실시간 강의실

GOD119는 기존 교회 홈페이지를 변경하지 않고 `Onch-0691/GOD119/` 경로에 별도로 설치한 강의 페이지입니다.

- 참석자 화면: https://kang-pastor79.github.io/Onch-0691/GOD119/
- 강사 화면: https://kang-pastor79.github.io/Onch-0691/GOD119/?teacher=1
- 설정 안내: https://kang-pastor79.github.io/Onch-0691/GOD119/setup.html
- 참석자 실습 제출 안내: https://kang-pastor79.github.io/Onch-0691/GOD119/submit.html

## 현재 구현 상태

- GitHub에 강사용·참석자용 웹 화면, 페이지 이동, 펜·형광펜·지우개·레이저 포인터 코드 등록
- Firebase 실시간 연결 설정 완료. 강사와 참석자 간 슬라이드 이동·판서 전송은 사용자 기기에서 검증됨 (60명 동시 부하 테스트는 별도 필요)
- Firebase 인증 설정이 완료되면 참석자는 로그인 없이 보기만 하고, 인증된 지정 강사 UID만 수정할 수 있도록 규칙 예시 마련
- 현재 원본 56장 PPT 슬라이드 이미지, 노트북 파일, 연결 동영상, 개인 경로는 **공개 저장소에 게시하지 않음**. 강의 페이지는 제목 기반의 안전한 미리보기를 표시

## 진행 순서

1. [강사 연결 안내](setup.html)에서 Firebase 프로젝트 생성 및 Google 로그인 설정
2. Realtime Database를 **잠금 모드**로 생성
3. [config.js](config.js)에 Firebase 웹 앱 설정 기입 (서비스 계정 비밀키는 절대 기입하지 않기)
4. 강사 화면에 Google 로그인하여 UID 확인
5. [firebase-rules.example.json](firebase-rules.example.json)을 Firebase 콘솔의 Realtime Database 규칙에 붙여넣고 UID 교체 후 게시
6. 두 노트북으로 슬라이드 이동·판서·지우개를 실제 테스트
7. 개인 정보·초상권·저작권 검토를 마친 자료만 공개 게시

## 중요한 보안 안내

GitHub Pages와 현재 제공하는 참석자 링크는 **공개 접근 가능한 웹사이트**입니다. `noindex`는 검색엔진에 대한 권고일 뿐 접근 통제가 아닙니다. 강의자료와 참여자 정보를 비공개로 해야 한다면 참석자 인증이 가능한 별도 서비스 구성이 필요합니다.

Firebase의 웹 설정(API 키 등)은 공개 웹 앱의 식별 정보이며 백엔드 비밀키가 아닙니다. 데이터 접근 권한은 **Firebase Security Rules**로 제한해야 합니다. 공개 GitHub에 서비스 계정 JSON, OAuth 비밀키, 비밀번호, 개인 노트북 파일을 올리지 마세요.

## MEGA 파일 요청 제출함 (2026-10-29 추가)

- 참석자 화면의 ‘실습 결과물 제출하기’에서 [submit.html](submit.html)로 이동합니다.
- 제출 안내 페이지는 제출자가 이름·소속에 맞는 **권장 파일명**을 생성하는 기능만 제공합니다. 입력값을 서버나 Firebase에 전송하지 않습니다.
- 실제 업로드는 사용자 제공 MEGA File Request `https://mega.nz/filerequest/MwN2xydC7XQ`에서 진행됩니다.
- 제출 폴더는 강사의 MEGA Cloud Drive에서 확인합니다. MEGA 제출 완료 여부나 제출자 명단을 GOD119가 자동 확인/집계하지 않습니다.
- 현재 MEGA 계정 화면에서 무료 용량 **15GB**가 표시되었습니다. 60명 대상 파일 1인 1개·200MB 이하를 **권장**합니다 (최대 약 12GB). 이는 안내 기준이지 서비스에서 강제되는 파일 크기 제한이 아닙니다.
- File Request 주소는 공개 페이지에 노출됩니다. 링크를 가진 사람은 누구나 파일을 제출할 수 있으므로 행사 종료 후 MEGA에서 파일 요청을 종료하고, 파일명에 들어간 이름과 교회명을 확인하십시오.
- 원본 56장 PPT 파일 및 비공개 개인정보는 공개 GitHub 저장소에 업로드하지 않았습니다.

## 60명 실습 제출 신고 및 강사 실시간 확인 (2026-10-30)

- 참석자: [실습 제출](submit.html) → MEGA 실제 파일 업로드 → **업로드 완료 체크** → **강사에게 제출 완료 알리기**
- 강사: [전용 실시간 제출 현황판](submissions-admin.html)에서 제출 신고 수, MEGA 확인 완료 수, 미확인 수 조회/이름 검색/CSV 다운로드
- 강사는 MEGA 드라이브에서 실제 파일을 확인한 뒤에만 ‘MEGA 수신 확인’을 누릅니다. 제출자 자기 신고와 MEGA의 실제 파일 수신은 **자동으로 대조되지 않습니다**.
- [익명 인증 활성화 및 비공개 데이터베이스 규칙 안내](submissions-setup.html)를 읽고 **Firebase 콘솔에서 직접 게시**해야 제출 신고 기능이 작동합니다.
- 필수 콘솔 설정: Authentication → Sign-in method → **Anonymous 사용 설정**, Realtime Database → Rules에 **강사 UID를 넣은 전체 보안 규칙 게시**.
- 구분된 DB 경로: 기존 강의실 경로는 공개 슬라이드·판서, 새 제출 경로는 참가자 본인 쓰기·읽기, 강사만 검수 및 전체 조회.
- 강사 UID는 공개 저장소에 게시하지 않습니다. 보안 규칙 파일은 강사 UID 자리표시자를 사용합니다.
- 참석자는 이메일/Google 로그인을 요구받지 않지만 Firebase 익명 계정을 사용합니다. 실제 파일은 Firebase에 업로드하지 않습니다.
- 익명 인증은 동일 외부 IP에서 단시간 대량 등록 시 제한될 수 있으므로 동일 와이파이에서 60명이 동시 신고하는 경우 **사전 시험**이 필요합니다.
- 제출 신고는 본인 입력이며 이름/소속을 강제 인증하지 않습니다. 참가자는 기기·브라우저를 변경하면 다른 UID로 신고할 수 있으므로 동일 인물의 중복 신고가 가능합니다.
- 제출자 이름, 교회, 신고 파일명 및 상태만 제한된 Firebase 경로에 보관합니다. 불필요한 개인정보는 강의 종료 후 삭제하세요.
- **실제 Firebase 콘솔 설정 및 60명 부하 테스트는 저장소 코드만 변경하여 완료할 수 없습니다.**

## 실시간 하이퍼링크 공유 (2026-10-31)

- 강사가 슬라이드의 등록된 하이퍼링크 또는 하단 웹 링크를 클릭하면 기존처럼 강사에게 새 탭이 열리며, Firebase Realtime Database의 `rooms/god119-seminar/sharedLink`에 슬라이드 번호·URL·클릭 시각이 기록됩니다.
- 참석자 강의실은 링크 공유 이벤트를 받아 슬라이드 위에 같은 주소의 웹페이지 또는 유튜브 임베드 영상을 자동으로 표시합니다.
- 외부 사이트의 X-Frame-Options/CSP 보안 정책에 따라 강의실 내 웹페이지 삽입이 막힐 수 있으므로 항상 '새 탭에서 자료 열기' 버튼을 제공합니다. 브라우저는 참석자에게 새 탭을 자동으로 열어주는 것을 차단할 수 있습니다. 유튜브는 각 참석자가 재생해야 하며 시간 동기화는 하지 않습니다.
- 강사는 '참석자 공유 화면 닫기' 버튼으로 해당 자료를 종료할 수 있습니다. 강사가 다음 슬라이드로 이동하면 `currentSlide`과 `sharedLink:null`을 한 번에 기록해 공유 화면을 닫습니다.
- 공유 이벤트는 강사용 Firebase 쓰기 규칙을 그대로 사용하므로 **별도 Firebase 규칙 교체는 필요하지 않습니다**. 참석자 명단이나 개인정보를 링크에 포함하지 않습니다.
- 실제 공유 가능한 외부 링크는 `index.html`의 `slideResources`에 정의된 항목(3, 11, 25번 등) 또는 강사가 입력한 10번 슬라이드 MEGA 파일 링크입니다. 44/53번 DOCX는 별도 연결이 필요합니다.

## 10번 슬라이드 — MEGA 클라우드 영상 연결 (2026-10-31)

- 10번 슬라이드의 왼쪽 또는 오른쪽 **영상 사진을 클릭**합니다. 처음 실행할 때만 작은 MEGA 링크 입력창이 나오며, 해당 MP4의 개별 파일 공유 URL을 한 번 저장하면 다음부터는 사진을 클릭하는 즉시 GOD119 안에 MEGA 플레이어가 열립니다. 폴더 링크는 지원하지 않습니다. 오른쪽의 큰 MEGA 설정 메뉴는 표시되지 않습니다.
- 링크 예시: `https://mega.nz/file/파일ID#복호화키` (해당 문자열은 **형식 예시일 뿐 실재 링크가 아님**). 파일 자체는 GitHub/Firebase로 복사하지 않습니다.
- 링크는 Firebase `rooms/god119-seminar/slide10Videos`의 `a`, `b`에 저장하고 기존 강사 쓰기 권한/공개 강의실 읽기 권한을 재사용합니다. 이 링크와 복호화키는 강의실 접속자에게 공개되므로 개인정보 등 민감한 파일을 등록해서는 안 됩니다.
- 강사가 10번 슬라이드 왼쪽/오른쪽 영상 사진을 클릭하면 해당 MEGA 링크가 실시간 공유됩니다. 강사와 참석자 모두 GOD119 안에서 MEGA의 전용 `/embed/` 플레이어를 볼 수 있습니다. 기기별 수동 재생이 필요할 수 있으며 재생 타임코드는 동기화되지 않습니다.
- **슬라이드로 돌아가기**를 누르면 Firebase의 `sharedLink`를 삭제해 양쪽 화면을 복귀시킵니다.
- MEGA 임베드를 차단하는 브라우저 환경이나 플레이어 문제에 대비해 **새 탭에서 자료 열기** 버튼이 있습니다.
- 노트북 영상 재생은 영상 사진 클릭 시 나타나는 작은 링크 설정창의 선택사항입니다. 강사 기기에만 재생되며 참석자에게 영상 바이트가 전송되지 않습니다.
