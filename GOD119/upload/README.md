# GOD119 새 슬라이드 업로드

1. `GOD119_New_56_Slides.zip` 파일을 이 폴더(`GOD119/upload/`)에 GitHub **Add file → Upload files**로 업로드합니다.
2. GitHub Actions의 `Install redesigned GOD119 slides`가 56개의 WebP 이미지를 검사하고 `GOD119/slides/slide-01.webp` ... `slide-56.webp`로 자동 교체합니다.
3. ZIP 안의 파일 이름은 `slide-01.webp`부터 `slide-56.webp`까지여야 합니다.
4. 기존 강의실 index.html 및 참석자/판서/Firebase 파일은 이 작업에서 수정하지 않습니다.
5. 배포가 완료되면 슬라이드 3번의 두 사역 링크와 11/25번 영상 링크의 새 클릭 위치를 조정합니다.

현재 ZIP은 업로드 대기 중입니다. 다른 파일은 올리지 마세요.
