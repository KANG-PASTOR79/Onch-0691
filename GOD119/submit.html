세미나에서 완성한 이미지 · PDF · TXT · MP4 파일을 목사님께 제출하는 안내 페이지입니다.

무료 · 파일명 변경 없이 제출

참석자 계정에 파일을 자동으로 연결할 수 있도록, GOD119에서 파일을 먼저 선택합니다. 파일 자체는 기존 MEGA 무료 제출함에 업로드합니다. 강사는 파일 내용 식별값으로 연결해 보므로 이름을 붙이거나 파일명을 변경하지 않아도 됩니다.

다른 참석자의 파일은 볼 수 없습니다. 개인정보, 비밀번호, 교인 명단 등 민감한 자료는 제출하지 마세요.

2 · 결과물 파일 선택

아직 파일을 선택하지 않았습니다.

선택한 파일은 강사 화면의 참석자 이름과 연결할 식별값을 만드는 데 사용합니다. 여기서 아직 업로드되지 않습니다.

📤 파일 제출하기 · MEGA 업로드 화면 열기

선택한 파일의 전송은 MEGA에서 이루어집니다. 노란 버튼을 누른 후 열리는 MEGA 화면에서 같은 파일을 다시 선택해 업로드해 주세요. 파일명은 변경하지 마세요. 현재 무료 MEGA 방식에서는 첫 번째 파일 선택을 다른 사이트에 자동 전달할 수 없습니다.

3 · 업로드 완료 확인

파일 선택 → 노란 제출 버튼으로 MEGA 업로드 → 여기에서 제출 완료 알리기 순서입니다.

선택한 파일의 크기와 내용 식별값을 해당 참석자의 계정에 기록합니다. 파일 자체는 MEGA에 보관되며, 강사 화면은 동기화 폴더에서 내용이 같은 파일을 찾습니다. 완전히 동일한 파일이 여러 개 있으면 강사가 선택해야 할 수 있습니다.
