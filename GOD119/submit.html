실습 결과물 제출

처음 참석하신 분은 먼저 GOD119 강의실에서 출석 등록을 해 주세요. 같은 브라우저에서 출석 등록과 제출 신고를 하면 강사 현황판에서 한 사람의 기록으로 연결됩니다.

세미나에서 완성한 이미지 · PDF · TXT · MP4 파일을 목사님께 제출하는 안내 페이지입니다.

무료 클라우드 제출 안내

1인당 파일 1개, 200MB 이하를 권장합니다. MEGA 무료 저장 공간에는 현재 15GB 한도가 표시되어 있습니다. 200MB 제한은 안내 사항이며, MEGA에서 자동 차단되지 않습니다. 필요한 경우 여러 파일을 압축하여 1개로 제출해 주세요.

파일 요청 링크를 가진 누구나 업로드할 수 있습니다. 개인정보, 비밀번호, 교인 명단 등 민감한 내용은 포함하지 마세요.

1 · 제출자 정보 확인

이름과 소속은 파일 이름을 만드는 데 사용됩니다. 아래에서 ‘제출 완료 신고’를 누르면 이 정보와 신고한 파일명이 Firebase에 비공개 저장되며 강사 화면에만 표시됩니다.

권장 파일 이름

이름_교회명_실습결과.pdf

실제 파일의 확장자는 원본 형식에 맞게 유지하세요. 예: PNG 사진은 .png, 마크다운은 .md

2 · MEGA 제출 페이지로 이동

①

컴퓨터 또는 태블릿에 저장된 실습 결과물 파일을 준비합니다.

②

위 권장 파일명으로 실제 파일을 이름 변경합니다. 복사 버튼은 이름 텍스트만 복사하며 파일을 자동 변경하지 않습니다.

③

아래 버튼으로 MEGA 파일 요청 페이지를 엽니다. 업로드 과정에서 이름을 묻는 경우 실제 제출자 이름을 적습니다.

↗ MEGA에 실습 결과물 제출하기

새 탭에서 MEGA 사이트가 열립니다. 파일을 실제로 업로드하고 MEGA의 완료 안내를 확인해야 제출이 끝납니다.

GOD119는 업로드 파일을 보관하거나 MEGA의 실제 파일 수신을 자동 확인하지 않습니다. 업로드 후 아래에서 신고하면 강사 현황판에 ‘미확인 신고’로 표시되고, 강사가 MEGA에서 확인한 뒤 ‘수신 확인 완료’로 변경합니다.

3 · MEGA 업로드 완료 신고

MEGA에서 파일 업로드를 마치고 완료 안내를 확인한 경우에만 아래 체크 후 신고해 주세요.

이름과 교회·소속을 입력하고 업로드 완료를 체크하세요. 신고에는 Firebase 익명 인증이 사용됩니다.

신고하기 버튼을 누르면 MEGA의 실제 업로드가 자동 확인되는 것은 아닙니다. 이름을 바꾸거나 다른 기기로 신고하면 중복될 수 있습니다.

4 · 제출 전 확인

파일명에 이름·교회명·실습결과가 있는지, 파일 크기가 권장 용량 이내인지 확인해 주세요. 파일 업로드에 문제가 있으면 강사에게 알려주세요.
